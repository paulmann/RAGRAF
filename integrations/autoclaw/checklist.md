# Чек-лист проверки (GUI)

Смоука нет: клиент не запускается без графического сеанса. Это названная
граница, а не «поддержка на словах». Проверка идёт по шагам, каждый наблюдаем.

1. Сервер добавлен в список MCP клиента, статус — подключён (зелёный).
2. Список инструментов содержит `ragraf_ensure`, `ragraf_search`, `ragraf_index_status`.
3. Запрос «приведи одну ссылку вида path:line по запросу onboarding» даёт ответ
   с адресом `файл:строка` — не пересказ и не «примерно там».
4. Ответ `ragraf_index_status` называет ревизию (`rev-…`) и `capability`.
5. Отключённый сервер: клиент показывает, что инструментов нет, — проверяется,
   что отсутствие видно, а не молчит.

Если пункт 3 не выполняется — интеграция не считается поддержанной: причина
записывается в отчёт, а не списывается на «модель не поняла».
