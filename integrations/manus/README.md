# Manus: подключение RAGRAF

Транспорт: **MCP по HTTP (если клиент это умеет)**. Конфигурация: `нет локальной конфигурации`.

## Подключение

Указать URL HTTP-транспорта RAGRAF (`python tools/ragraf-mcp-http.py`) в настройках MCP облачного клиента.

Полный шаблон — `manus.template.json` в этом каталоге. Значений секретов в нём нет:
ключи живут в хранилище RAGRAF или в окружении, а не в файле конфигурации.

## Проверка

Чек-лист `checklist.md`: проверяется только доступность HTTP-транспорта.

## Уровни

| Уровень | Состояние |
|---|---|
| L1 — шаблон конфигурации | есть, разбирается тем же разборщиком, что продукт |
| L2 — смоук | нет: клиент не автоматизируется, вместо него `checklist.md` |
| L3 — проверка в чекере | `python tools/check_integrations.py` и 46-я проверка `tools/Invoke-ProjectDoctrine.ps1` |
| L4 — границы названы | раздел «Границы» ниже |
| L0 — установка на стенде | облачный SaaS, локальной установки нет |

## Границы

* Локальной установки нет: L0 не измеряется, смоука нет.
* Облачный клиент не должен получать доступ к локальному корпусу без решения владельца: в шаблоне только loopback-адрес.
* Токен доступа HTTP-транспорта в шаблон не вписывается.

Стенд для чистых установок — 192.168.31.103 (решение владельца): на рабочей
машине живёт индекс, и ставить туда клиентов «для проверки» нельзя.
