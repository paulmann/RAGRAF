# Соглашение об уровне обслуживания (SLA) — ЧЕРНОВИК

> **Статус: черновик, не для публикации.** Числа сроков — решение владельца;
> здесь зафиксирована СТРУКТУРА и то, что продукт действительно умеет, чтобы
> обещания не расходились с кодом. Места решения помечены `[ВЛАДЕЛЕЦ: …]`.

## 1. Область

1.1. Соглашение касается издания `[ВЛАДЕЛЕЦ: Pro / Enterprise]`. Community-издание
поставляется «как есть» без гарантий сроков.

1.2. Продукт — локальный инструмент. SLA не может обещать доступность сервиса,
которого нет: сроки относятся к реакции на обращение и к выпуску исправлений.

## 2. Уровни поддержки

| Уровень | Канал | Реакция | Исправление критичного | Что входит |
|---|---|---|---|---|
| Community | GitHub Issues репозитория | без гарантии срока | по возможности | документация, публичные дефекты |
| Standard | `[ВЛАДЕЛЕЦ: почта/портал]` | `[ВЛАДЕЛЕЦ: 1 раб. день]` | `[ВЛАДЕЛЕЦ: 10 раб. дней]` | консультации по установке и настройке, разбор дефектов |
| Enterprise | `[ВЛАДЕЛЕЦ: канал + дежурство]` | `[ВЛАДЕЛЕЦ: 4 часа]` | `[ВЛАДЕЛЕЦ: 3 раб. дня]` | всё из Standard + помощь при обновлении, разбор инцидентов безопасности, консультация по закрытому контуру |

## 3. Что считается критичным

3.1. Критично: утечка значения секрета из хранилища; отказ панели или индексатора
запускаться; повреждение журнала аудита; ложное заявление `capability: full`.

3.2. Не критично: расхождение формулировок в документации; отсутствие языка в
разборе; недоступность необязательного слоя (Joern, GPU, модель эмбеддингов) —
продукт в этих случаях деградирует с названной причиной, и это заявленное
поведение, а не дефект.

## 4. Обязанности владельца продукта

4.1. Выпускать исправления безопасности для поддерживаемой ветки; публиковать
изменения в `CHANGELOG.md`; не выпускать исправление, не имеющее проверки,
которая краснеет на прежнем состоянии (`tools/Invoke-ProjectDoctrine.ps1`).

4.2. Предупреждать о прекращении поддержки ветки не позднее
`[ВЛАДЕЛЕЦ: 6 месяцев]`.

## 5. Обязанности Лицензиата

5.1. Предоставлять воспроизводимый отчёт: версия продукта, ревизия индекса,
команда, вывод. Без этого сроки реакции не применяются — это записано в
`community/SECURITY.md` и в правилах проекта.

5.2. Держать резервные копии каталога `catalog/` (мастер-ключ хранилища и ключ
подписи): их потеря не восстанавливается средствами продукта.

## 6. Границы

6.1. SLA не покрывает: сторонние сбои (GitHub, PyPI, HuggingFace), последствия
правок кода Лицензиата, работу за пределами поддерживаемых версий Python и ОС.
