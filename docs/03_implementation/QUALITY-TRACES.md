# Трассы подтверждённых сбоев

Этап X7, работа B. Вопрос: **чем именно падал кейс и можно ли это повторить.**
Прогон качества отвечает «падает или нет» и не сохраняет, ЧЕМ падал: журнал шагов
живёт своей жизнью, объявление кейса правится, и через неделю нельзя ни повторить
сбой, ни доказать, что он был.

## 2. Что лежит в трассе

Не текст ошибки, а всё нужное для повтора:

- объявление кейса **целиком** (а не ссылка на файл: файл правится), плюс
  `case_source` — откуда оно взято на момент записи;
- шаги сеанса из журнала вызовов (предел 500 — трасса это доказательство, а не
  копия журнала);
- решения гейта сеанса (предел 200): ими подтверждается обход, а не только шаги;
- ревизия индекса и сеанс;
- состояние до и после повтора.

Ревизия обязательна: трасса без ревизии не воспроизводима — неизвестно, на каком
индексе она снята.

## 3. Виды вызова

```
python tools/ragraf.py query quality_trace                                  # list
python tools/ragraf.py query quality_trace --trace-action save \
    --case-id steps-ensure --session <id>                                    # save
python tools/ragraf.py query quality_trace --trace-action replay --trace-id 7 # replay
```

- **save** записывает только сбой. Пройденный кейс — не трасса, иначе журнал
  сбоев стал бы журналом прогонов и «сколько раз падало» перестало бы читаться.
  Повтор того же сбоя возвращает прежний `trace_id` (`saved: false`) — это ответ,
  а не ошибка.
- **list** компактен: без содержимого. Содержимое — только у `replay` и `load`.
- **replay** повторяет сохранённое объявление на текущем индексе и называет
  вердикт.

## 4. Вердикты повтора

| вердикт | смысл |
|---|---|
| `still_failing` | падение осталось падением |
| `fixed` | прошло на **той же** ревизии |
| `other_rev` | прошло на **другой** ревизии: это не исправление, а другая история |
| `not_reproducible` | трассы нет или оценка не выполнилась (причина названа) |

Правило «`fixed` только на той же ревизии» — не педантизм: на другой ревизии
падение могло уйти по другой причине, и заявлять исправление значило бы выдавать
совпадение за работу.

## 5. Границы

- Оценивается **процесс** (шаги, запреты, обход гейта), а не качество текста
  ответа: для текста нужна модель, и это названо в документе кейсов.
- Журнал шагов ограничен последними вызовами сеанса: если сеанс убран
  прореживанием, повтор честно скажет `not_reproducible`.
- Трассы живут в журнале управления и не участвуют в ротации ревизий: у них нет
  `rev_id`, а ревизия — поле записи.

## 6. Чем проверено

`tests/test_quality_traces.py` (42 свойства): отказ на пройденном кейсе и на
кейсе без состояния, обязательность ревизии, полный состав трассы, повтор без
дублей, канонический отпечаток, компактный список, четыре вердикта, связка с
проверкой кейсов на журнале `usage_call` (сбой → `still_failing`, появление
шага → `fixed`), обрезка шагов и отсутствие роста журнала от чтения.
