# Подготовка корпуса к индексации (X5)

Документ поставки этапа X5 (блоки 9 + 5 плана). Отвечает на два вопроса, которые
до этапа задавались уже после работы: **сколько будет стоить индекс** и **что он
не покроет**. И на третий, служебный: **что именно сказать агенту, когда операция
невозможна**.

Обновлён: 09.11.2026. Проверки: `python tests\test_preflight.py` (34 свойства).

## 1. Операция `preflight`

`preflight(root, sample=50)` — осмотр каталога **до** создания корпуса
(`src/ragraf/preflight.py:348`, операция — `src/ragraf/facade.py:1701`). Операция
НИЧЕГО не создаёт: ни `.ragraf`, ни каталога, ни файла. Это не обещание, а
свойство набора: полный снимок каталога (файлы и подкаталоги) до и после вызова
совпадает.

| что отвечает | как измерено | граница |
|---|---|---|
| число файлов и распределение по расширениям | обход с отсечением служебных каталогов | обход ограничен `MAX_FILES_WALKED` |
| доля сгенерированного кода | маркеры (`auto-generated`, `do not edit`, `code generated by`) в первых 4 КБ файла | нижняя оценка: маркер ниже 4 КБ не виден |
| миграции | пути и имена файлов (`migration`, `migrate`, `миграции`) | содержимое SQL не разбирается |
| ожидаемое время разбора | `tree_sitter` на выборке тем же парсером, что у индексатора | это замер цены, а не гарантия |
| слепые зоны динамики | шаблоны по языкам с адресом `файл:строка` | шаблон — не полный разбор |
| готовность векторов | библиотека + модели в кэше | каталог моделей НЕ создаётся |
| готовность Joern | скрипты Joern и `java` в PATH | запуск не проверяется: только наличие |
| эффект исключений | правила конфига против обхода | считается по правилу, а не по индексу |

### Погрешность оценки времени
Считается в `src/ragraf/preflight.py:189` (`_parse_sample`): замер на выборке, две половины, расхождение в промилле.

Выборка детерминирована: шаг по отсортированному списку файлов с разбором
деревом. Погрешность — расхождение половин выборки в промилле, а не «плюс-минус
на глаз»: файлы разной величины покажут это числом.

При выборке, равной числу файлов, `error_promille` равно нулю и метод говорит
«замер, а не экстраполяция» — ноль здесь означает именно это, а не «не измерено».
Если парсер недоступен, `timing.available` равно `false`, а `reason` называет
причину: «нечем измерить» и «измерено, вышло мало» — разные состояния. По той же
причине оценка меньше миллисекунды показывается как 1: ноль читался бы как
«время не измерялось».

### Слепые зоны динамики

Статический разбор не видит вызов, имя которого собирается во время выполнения.
Такие места — не дефект кода, а **граница метода**, и `preflight` называет их до
начала работы: иначе «в графе нет вызова» читается как «вызова нет в коде».

| язык | что ищется |
|---|---|
| PHP | `call_user_func`/`call_user_func_array`, `$obj->$method()`, `$this->{$name}()`, `new $class`, `eval`, `Reflection*` |
| Python | `getattr`, `eval`, `exec`, `import_module`/`__import__`, `globals()[...]`/`setattr` |
| JS/TS | `eval`, `new Function`, вызов по строковому ключу `obj['name']()` |
| C# | `GetType()`, `GetMethod`, `dynamic`, `InvokeMember` |
| Java | `getMethod`, `getDeclaredMethod`, `Class.forName` |

У каждого найденного места в ответе `address` = `путь:строка` и короткая цитата.

## 2. Единый текст отказа

`util.next_action(operation, arg, kind=..., detail=...)` (`src/ragraf/util.py:586`) возвращает четыре
обязательные части:

| поле | смысл |
|---|---|
| `problem` | что не так (с подробностью, если она передана) |
| `why` | почему так вышло — одна фраза |
| `action` | ОДНА готовая команда; пусто, если исправить нельзя |
| `possible` | возможно ли выполнить операцию вообще (после действия или с другим входом) |

Виды отказа — закрытый список: `no_index`, `stale_index`, `no_documents`,
`feature`, `edition`, `license`, `degraded`, `no_data`, `bad_input`. Вид вне
списка — ошибка вызывающего кода, а не пустой совет: опечатка в имени не должна
давать «ничего не посоветовали».

Подключено в отказах: «индекса нет» (`_no_index`, `src/ragraf/facade.py:7388`), «возможность не в сборке»
(`_feature_refusal`), «издание закрыто» и «лицензия недействительна»
(`_edition_refusal`), «режим ниже full» (`slice`), а также в исключении
`IndexNotBuilt`, которое поднимается при сборке фасада.

Отказ не превращается в трассировку: если совет пришёл неполным, текст берётся
запасной, а `next_action` остаётся в ответе. Это проверено подсадкой в наборе.

## 3. Что не является платной возможностью

Считать файлы по расширениям умеет любой `ls`; платная часть `preflight` — не
подсчёт, а **ответ «что не покроется»**: список мест, где вызов собирается во
время выполнения, и измеренная цена разбора с погрешностью. Именно эти два числа
превращают «давайте проиндексируем» в решение с границами.
