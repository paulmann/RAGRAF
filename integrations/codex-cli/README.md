# OpenAI Codex CLI: подключение RAGRAF

Транспорт: **MCP stdio**. Конфигурация: `~/.codex/config.toml`.

## Подключение

Добавить раздел `[mcp_servers.ragraf]` из `codex.template.toml` в `~/.codex/config.toml`.

Полный шаблон — `codex.template.toml` в этом каталоге. Значений секретов в нём нет:
ключи живут в хранилище RAGRAF или в окружении, а не в файле конфигурации.

## Проверка

`pwsh -NoProfile -File integrations/codex-cli/smoke.ps1` — `codex exec` с тем же заданием.

## Уровни

| Уровень | Состояние |
|---|---|
| L1 — шаблон конфигурации | есть, разбирается тем же разборщиком, что продукт |
| L2 — смоук | есть `smoke.ps1`; прогон на этой машине: клиент не авторизован (код 3) |
| L3 — проверка в чекере | `python tools/check_integrations.py` и 46-я проверка `tools/Invoke-ProjectDoctrine.ps1` |
| L4 — границы названы | раздел «Границы» ниже |
| L0 — установка на стенде | codex-cli 0.166.0 |

## Границы

* Смоук требует ключа провайдера в окружении: без него код 3.
* Песочница Codex может запрещать сеть и файлы вне проекта — это её настройка, а не RAGRAF.

Стенд для чистых установок — 192.168.31.103 (решение владельца): на рабочей
машине живёт индекс, и ставить туда клиентов «для проверки» нельзя.
