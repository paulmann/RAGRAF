# OpenClaw: подключение RAGRAF

Транспорт: **MCP stdio**. Конфигурация: `~/.openclaw/openclaw.json`.

## Подключение

Положить блок из `openclaw.template.json` в раздел `mcp.servers` файла `openclaw.json` (создать раздел, если его нет). Ключ `ragraf` — имя сервера в ответах агента.

Полный шаблон — `openclaw.template.json` в этом каталоге. Значений секретов в нём нет:
ключи живут в хранилище RAGRAF или в окружении, а не в файле конфигурации.

## Проверка

`pwsh -NoProfile -File integrations/openclaw/smoke.ps1` — headless-прогон: клиент вызывает `ragraf_ensure` и `ragraf_search`, ответ обязан содержать ссылку вида `path:line`.

## Уровни

| Уровень | Состояние |
|---|---|
| L1 — шаблон конфигурации | есть, разбирается тем же разборщиком, что продукт |
| L2 — смоук | есть `smoke.ps1`; прогон на этой машине: клиент не авторизован (код 3) |
| L3 — проверка в чекере | `python tools/check_integrations.py` и 46-я проверка `tools/Invoke-ProjectDoctrine.ps1` |
| L4 — границы названы | раздел «Границы» ниже |
| L0 — установка на стенде | OpenClaw 2026.10.5 |

## Границы

* Gateway-режим и веб-интерфейс не проверяются: поддержка означает headless-вызов из CLI.
* Смоук требует авторизованного клиента: без входа он вернёт код 3 и скажет об этом.
* Инструменты RAGRAF видны агенту после перезапуска клиента: окно конфигурации кэширует список.

Стенд для чистых установок — 192.168.31.103 (решение владельца): на рабочей
машине живёт индекс, и ставить туда клиентов «для проверки» нельзя.
