# Отчёт X2 — поверхность и числа

Дата: 2026-11-09. Этап: X2 плана `docs/plans/PLAN-PRO-ENTERPRISE-2026-11-09.md`
(блок 8). Издание: не товар — дисциплина сборки. Коммитов нет: в дереве нет `.git`.

## 1. Задача

Сделать так, чтобы число в документации не могло разойтись с кодом молча:
единственный источник чисел, генератор по разметке, гейт в проверках, артефакт
поставки для сайта.

## 5. Ограничения, названные прямо

- **Alt-текст обложки** не размечается: HTML-комментарий внутри alt попал бы в
  текст для чтения с экрана. Число там правится руками при выпуске.
- **47 операций** собирают ответ из переменной, ключи статически не видны; это
  названо в `notes` ответа `surface.collect`, а не выдано за пустой ответ. Для
  пиннинга подписи (X6) их придётся описывать отдельно.
- **Сайт** вне репозитория: гейт проверяет репозиторий и пишет `docs/surface.json`
  для поставки; страницу правит отдельный промт.
- **Порядок обязателен**: `surface_gen --write` меняет README, поэтому следом
  нужен `registry_line --write` — иначе `check_pro_delivery` откажет на хэшах
  переводов в таблице источников (проверено: отказ воспроизведён и снят).
- **Ревизия** в артефакте обновляется, но в отпечаток не входит: иначе каждая
  переиндексация делала бы гейт красным на неизменном коде.

## 6. Побочное, о чём надо знать

Попытки `ragraf ensure`/`check` на живом дереве (X1) оставили три незавершённые
ревизии `rev-1481…1483` в состоянии `building`. Они закрыты штатным
`ControlStore.close_abandoned(600)` как `aborted` (событие `rev_closed_stale`),
активная ревизия осталась `rev-1477`. Данные не удалялись: у этих ревизий их нет.

## 7. Откат

1. Убрать маркеры `<!-- surface:* -->` из восьми документов, числа останутся
   верными на момент отката.
2. Удалить `docs/surface.json`, `src/ragraf/surface.py`,
   `tools/surface_gen.py`, `tools/surface_templates.json`,
   `docs/03_implementation/SURFACE-NUMBERS.md`; вернуть `tools/surface_counts.py`
   к самостоятельному счёту.
3. Вернуть `tests/test_documented_numbers.py` к прежней редакции (76 → 62
   проверки).

Код продукта и данные не затронуты: этап меняет только способ получить число.

## 8. Использование RAGRAF

Ревизия: `rev-1477`. Обращений к операциям RAGRAF — ноль: `ensure`/`check` на
живом дереве не завершаются за отведённое время (полный обход), работа шла
чтением файлов. Числа в отчёте получены из `surface.collect` и прогонов,
названных в §3; каждое утверждение имеет адрес.
