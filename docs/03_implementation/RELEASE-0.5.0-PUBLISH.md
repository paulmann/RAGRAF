## 3. Коммит и тег

Подпись — идентичность владельца, а не агента (правило §10.8 пользовательских правил):

```bash
git fetch origin main
git rev-list --left-right --count HEAD...origin/main    # "<впереди> <позади>"
# «позади» больше нуля — сначала слить, потом отправлять; --force не применять
git add -A -- ':!catalog' ':!.ragraf' ':!.interpreter' ':!skills-lock.json' ':!*.bak'
git status --short
git -c user.name='<владелец>' -c user.email='<почта>' commit -m "выпуск 0.5.0: документный слой, проверка запуска поставки"
git log -1 --format='%an <%ae> | %cn <%ce>'             # ожидается владелец, НЕ zwork
git tag -a v0.5.0 -m "RAGRAF 0.5.0 — документный слой"
git push origin main --follow-tags
```

Если коммит уже ушёл с подписью агента — `git commit --amend --reset-author --no-edit`
(переменные `GIT_AUTHOR_*` предварительно снять), дерево до и после сверить
`git rev-parse 'HEAD^{tree}'`.

## 4. После публикации

1. `docs/03_implementation/RELEASE-SOURCES.md`: столбец «sha256 в публичном main»
   заполняется по опубликованному коммиту, «совпадает» пересчитывается сравнением двух
   хэшей. До публикации у трёх файлов честно стоит «нет».
2. `python tools\registry_line.py --write` → `ragraf.py reindex` → чекер.
3. Проверка из опубликованного: клон в отдельный каталог → `pip install -e .` →
   `ragraf --version` = `0.5.0` (консольный скрипт из `pyproject.toml`; **не**
   `python -m ragraf` — такого модуля нет, проверено 30.10.2026; равнозначно
   `python -m ragraf.cli --version`) → `python tools\check_release_runs.py`.

**Важно про конфиг корпуса.** В клоне НЕТ `config/ragraf.yaml`: живой конфиг не
поставляется (`tools/release/manifest.toml:212-219` — в нём абсолютный путь автора),
вместо него есть `examples/ragraf.example.yaml`. Поэтому индексация в клоне делается
созданием своего корпуса:

```powershell
python tools\ragraf.py init C:\temp\mycorpus --name mycorpus --config C:\temp\mycorpus.yaml
python tools\ragraf.py -p C:\temp\mycorpus.yaml index
python tools\ragraf.py -p C:\temp\mycorpus.yaml query index_status
```

Проверено 30.10.2026 на собранном дереве: `init` и `index` отвечают кодом 0; CPG при
этом честно помечается недоступной («скрипты Joern не найдены»), и это ожидаемо —
Joern в поставку не входит.

## 5. Откат

Тег и коммит отзываются на стороне владельца; локальное дерево от публикации не
меняется. Если публикация окажется неполной (забыт файл из манифеста), честный путь —
новый коммит `0.5.1`, а не `--force` по опубликованной истории.
