# OpenCode: подключение RAGRAF

Транспорт: **MCP stdio**. Конфигурация: `opencode.json`.

## Подключение

Слить блок `mcp.ragraf` из `opencode.template.json` в `opencode.json` проекта.

Полный шаблон — `opencode.template.json` в этом каталоге. Значений секретов в нём нет:
ключи живут в хранилище RAGRAF или в окружении, а не в файле конфигурации.

## Проверка

`pwsh -NoProfile -File integrations/opencode/smoke.ps1` — `opencode run`.

## Уровни

| Уровень | Состояние |
|---|---|
| L1 — шаблон конфигурации | есть, разбирается тем же разборщиком, что продукт |
| L2 — смоук | есть `smoke.ps1`; прогон на этой машине: клиент не авторизован (код 3) |
| L3 — проверка в чекере | `python tools/check_integrations.py` и 46-я проверка `tools/Invoke-ProjectDoctrine.ps1` |
| L4 — границы названы | раздел «Границы» ниже |
| L0 — установка на стенде | opencode 1.19.5 |

## Границы

* Смоук требует настроенного провайдера модели (код 3, если нет).
* Формат `command` массивом проверяется разбором: у старых версий он строкой.

Стенд для чистых установок — 192.168.31.103 (решение владельца): на рабочей
машине живёт индекс, и ставить туда клиентов «для проверки» нельзя.
