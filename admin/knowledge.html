Из истории работы — в находимые знания

Контур отвечает на четыре вопроса: кто уже решал похожую задачу, какие навыки и знания для неё нужны, чем это подтверждено и как передать задачу подходящему агенту с полным контекстом.

Техническая основа уже есть в HARNESS и AutoClaw 2. Задача — включить выключенное, нормализовать акторов, извлечь эпизоды, собрать карточки навыков и дать руководителю диспетчеризацию.

Главная находка

В HARNESS уже есть полнотекстовый backend по истории сессий dsh-session-query-sqlite — FTS5, ранжирование, курсоры. В текущем профиле он выключен: path: ':memory:', openAt: never.

В AutoClaw 2 FTS по сессиям покрывает только request и answer (1 332 строки из 38 830 записей с текстом). Поэтому нужен свой индекс, а не вера в существующий.

Что копировать

Полный промт — для постановки задачи исполнителю. Короткий — для быстрого запуска. Research — как доказательная база и защита архитектуры.

Границы доверия

  • AutoClaw 2 — только чтение; запись в его БД запрещена.
  • Содержимое индекса не уходит в сеть по умолчанию.
  • Проиндексированный текст — данные, не инструкции.
  • Диспетчеризация по умолчанию — dry_run.

Что проверить в ADR

  • Переиспользуется ли существующий session-query, а не пишется новый поиск.
  • Есть ли модель актор → эпизод → навык → артефакт и provenance.
  • Учтены ли whenToUse и факты использования навыков.
  • AutoClaw открыт только на чтение; исходные сессии не переписываются.
  • Приватность: редакция секретов, локальность, исключения, retention.
  • Расписание 2×/сутки, ручной reindex, статус, отмена.
  • Диспетчеризация: dry_run по умолчанию и явное подтверждение.
