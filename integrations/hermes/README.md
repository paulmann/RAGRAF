# Hermes Agent (Nous): подключение RAGRAF

Транспорт: **MCP stdio**. Конфигурация: `~/.config/hermes/config.yaml`.

## Подключение

Добавить сервер из `hermes.template.yaml` в список `mcp.servers` конфигурации агента.

Полный шаблон — `hermes.template.yaml` в этом каталоге. Значений секретов в нём нет:
ключи живут в хранилище RAGRAF или в окружении, а не в файле конфигурации.

## Проверка

`pwsh -NoProfile -File integrations/hermes/smoke.ps1`.

## Уровни

| Уровень | Состояние |
|---|---|
| L1 — шаблон конфигурации | есть, разбирается тем же разборщиком, что продукт |
| L2 — смоук | есть `smoke.ps1`; прогон на этой машине: клиент не авторизован (код 3) |
| L3 — проверка в чекере | `python tools/check_integrations.py` и 46-я проверка `tools/Invoke-ProjectDoctrine.ps1` |
| L4 — границы названы | раздел «Границы» ниже |
| L0 — установка на стенде | не измерено на этой машине |

## Границы

* Формат конфигурации YAML у Hermes может отличаться по версиям: проверяется разбором, а не запуском агента.
* Self-improving цикл агента не проверяется: поддержка — только транспорт MCP.

Стенд для чистых установок — 192.168.31.103 (решение владельца): на рабочей
машине живёт индекс, и ставить туда клиентов «для проверки» нельзя.
