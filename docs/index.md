# RAGRAF

RAGRAF — графово-векторная база знаний о коде для LLM-агентов. Агент задаёт
вопрос **фиксированной операцией** (`search`, `symbol`, `callers`, `impact`,
`slice`, `policy_trace`, …) и получает факт со ссылкой `файл:строка`, а не
десяток кандидатов на просмотр. Индекс живёт локально: SQLite, полнотекстовый
поиск FTS5, векторы, граф вызовов и — когда есть Joern — граф свойств кода.

## Что важно знать сразу

- **Свежесть измеряется, а не обещается.** У корпуса есть контрольная сумма;
  при расхождении операция отвечает `stale` и запускает переиндексацию, а не
  выдаёт прошлое состояние за настоящее.
- **Режим не завышается.** `capability: full` означает «доступны операции
  среза», то есть в графе есть рёбра от свойств кода. Нет Joern — будет
  `partial` с причиной, а не ложное «всё готово».
- **Деградация вместо падения.** Нет модели эмбеддингов, видеокарты или Java —
  честная пометка и причина.

## Первые три команды

```powershell
python tools/ragraf.py ensure <каталог проекта>    # найти корпус, обновить отставший индекс
python tools/ragraf.py -p config/ragraf.yaml check # свежесть и режим
python tools/ragraf.py -p config/ragraf.yaml query search "что ищем"
```

Установка, подключение к агенту и полный перечень операций — в разделах ниже.

## О языке документации

Сайт собирается из того же каталога `docs/`, что лежит в репозитории: страница
не может разойтись с файлом, который читатель найдёт рядом с кодом. Документы
написаны по-русски — это язык, на котором ведётся работа; `README.md` и
`README.ru.md` в корне дают краткое описание на двух языках.
