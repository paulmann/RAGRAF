# Якоря замысла в коде (X3)

Документ поставки. Отвечает на вопрос, который остался открытым при вводе
`contract-drift`: **что делать, если замысел уже написан в коде, но не в манифесте**.
Ответ — якоря: размеченные блоки комментариев с закрытым списком ключей, которые
RAGRAF разбирает и проверяет. Манифест при этом остаётся старшим входом.

Обновлён: 09.11.2026. Проверки: `python tests\test_contracts_anchors.py` (35
свойств) и `python tests\test_contracts.py` (44 свойства, поведение по умолчанию
не изменилось).

## 1. Почему якоря не отменяют решение о манифесте

При вводе `contract-drift` было записано: замысел, размазанный комментариями внутри
кода, нельзя ни проверить, ни потребовать, поэтому замысел живёт во внешнем
`contracts.yaml` (`src/ragraf/contracts.py:7-8`). Это решение не отменяется.
Якоря допускаются на одном условии — **они проверяемы**:

| свойство | манифест | якорь |
|---|---|---|
| разбор | YAML + схема `schema: 1` | построчный разбор с закрытыми списками ключей |
| адрес находки | строка манифеста | `path:line` в файле кода |
| неизвестный ключ | ошибка схемы | находка `markup_malformed` |
| кто главнее | — | манифест (`anchor_conflict` называет оба адреса) |

Якорь без проверки был бы комментарием, который выглядит как контракт. Поэтому
список ключей закрыт: `PURPOSE`, `SCOPE`, `DEPENDS`, `LINKS`, `ROLE`, `MAP_MODE`
у модуля; `INPUTS`, `OUTPUTS`, `SIDE_EFFECTS` у контракта. Ключ вне списка — не
«пропустим молча», а находка.

## 2. Разметка

```python
# START_MODULE_CONTRACT
# PURPOSE: выпуск токенов
# SCOPE: src/auth/tokens.py
# LINKS: M-TOKENS
# DEPENDS: M-CORE
# MAP_MODE: EXPORTS
# MODULE_MAP: extract_token
# END_MODULE_CONTRACT
#
# START_CONTRACT: extract_token
# INPUTS: req
# OUTPUTS: str | None
# SIDE_EFFECTS: none
# END_CONTRACT: extract_token
```

Что разбирается:

| блок | смысл | что проверяется |
|---|---|---|
| `START_MODULE_CONTRACT … END_MODULE_CONTRACT` | модуль | наличие `LINKS` (идентификатор), парность, уникальность в файле |
| `START_CONTRACT: имя … END_CONTRACT: имя` | контракт узла | парность имени, принадлежность модулю файла, закрытый список ключей |
| `MODULE_MAP: a, b` или блок `START_MODULE_MAP … END_MODULE_MAP` | объявленные экспорты файла | совпадение с фактическими экспортами в обе стороны |
| `START_BLOCK_* … END_BLOCK_*` | границы участка | только парность (семантики не несёт) |

Модуль якоря — это тот же модуль манифеста по смыслу: `id` = первый элемент
`LINKS`, `files` = файл, в котором стоит якорь, `depends_on` = `DEPENDS`. Поэтому
сверка с вычисленным графом не дублируется: обе стороны приводятся к одной форме
(`src/ragraf/anchors.py:277`, слияние — `src/ragraf/contracts.py:637`).

`START_CONTRACT` может стоять и внутри блока модуля, и после него — но только в
файле, где модуль объявлен (`src/ragraf/anchors.py:126`). Иначе контракт не имеет
модуля, и это находка, а не догадка.

## 3. Операция

`contract_drift` получила параметр `source`:

| `source` | что читается | когда нужен |
|---|---|---|
| `manifest` (по умолчанию) | только `contracts.yaml` | прежнее поведение, ни байта разницы |
| `anchors` | только якоря в коде | проект без манифеста |
| `both` | оба входа, манифест главнее | переходный период |

CLI: `query contract_drift --declared-source anchors` (флаг назван
`--declared-source`, потому что `--source` уже занят разбором каталогов). MCP:
поле `source` у `ragraf_contract_drift`.

Ответ получает два новых раздела, не меняя существующих:

- `declared` — откуда взят замысел и сколько объявлений с каждой стороны:
  `manifest_modules`, `manifest_contracts`, `anchor_modules`, `anchor_contracts`,
  `conflicts`;
- `anchors` — сколько файлов-кандидатов, сколько прочитано, сколько находок
  разметки, сколько проверено карт, сколько рёбер осмотрено и признак усечения.

Когда якорей нет — `found=false`, причина `no anchors` и код 0: это состояние
проекта, а не сбой.

## 4. Виды расхождений: 6 → 11

Список остаётся закрытым (`src/ragraf/contracts.py:69`). Пять новых видов видны
только при `source=anchors|both`:

| вид | что означает | адрес |
|---|---|---|
| `declared_edge_missing` | модуль объявил `DEPENDS`, вызовов в файлы зависимости нет | строка `DEPENDS` |
| `computed_edge_unexpected` | вызов в чужой модуль, которого нет в `DEPENDS` | файл и строка ЦЕЛИ вызова |
| `anchor_conflict` | якорь и манифест расходятся; действует манифест | адрес якоря + `manifest_address` |
| `markup_malformed` | разметка нарушена (парность, дубль, ключ вне списка) | `path:line` нарушения |
| `map_mismatch` | `MODULE_MAP` расходится с экспортами файла | адрес якоря или адрес экспорта |

## 5. Как считаются рёбра между модулями

Полный обход рёбер живого корпуса (4,7 млн на rev-1477) — цена без пользы. Считаются
только рёбра, у которых источник — узел в файле объявленного модуля
(`src/ragraf/contracts.py:562`). Цель разрешается двумя способами:

1. узел с файлом → модуль этого файла;
2. заглушка внешнего вызова (`kind=external`, файла нет) → модуль по имени, если
   это имя экспортируется ровно одним модулем. Имя, которое экспортируют два
   модуля, доказательством не считается и в статистику уходит как неразрешённое
   (`edge_unresolved`).

Причина второй ветки измерена: после разбора `from .tokens import extract_token`
вызов `extract_token(req)` приходит ребром `calls_heuristic` в заглушку
`python:extract_token` без файла. Без разрешения по имени «вызов в другой модуль»
не находился вовсе, и `declared_edge_missing` срабатывал на здоровом коде.

## 6. Чего якоря не делают

- **Не выводят сигнатуру.** `INPUTS`/`OUTPUTS` — описание для человека, а не
  машинная подпись; сверка сигнатуры остаётся у манифеста и названа в отчёте.
- **Не переписывают исходники.** sha256 файлов до и после вызова совпадают —
  это проверяется свойством набора.
- **Не осматривают весь корпус.** Кандидаты берутся из индекса (комментарии с
  якорем), а если комментариев в индексе нет — по путям узлов, с пределом 500
  файлов (`MAX_ANCHOR_FILES`). Файл с якорем вне индекса не осматривается, и это
  названо в `limits`, а не выдано за «якорей нет».

## 8. Откат

Якоря не меняют ни хранилищ, ни индекса, поэтому откат — это откат кода:
`source` по умолчанию равен `manifest`, и при нём разбор якорей не запускается
вовсе. Достаточно вернуть прежние `contracts.py`, `facade.py`, `cli.py`,
`mcp_server.py` и удалить `anchors.py`.
