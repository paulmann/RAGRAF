# Cline (расширение VS Code): подключение RAGRAF

Транспорт: **MCP stdio**. Конфигурация: `cline_mcp_settings.json`.

## Подключение

Открыть MCP Servers → Edit MCP Settings и вставить блок из `cline.template.json`.

Полный шаблон — `cline.template.json` в этом каталоге. Значений секретов в нём нет:
ключи живут в хранилище RAGRAF или в окружении, а не в файле конфигурации.

## Проверка

Чек-лист `checklist.md`: пять шагов, каждый наблюдаем в интерфейсе.

## Уровни

| Уровень | Состояние |

| L1 — шаблон конфигурации | есть, разбирается тем же разборщиком, что продукт |

* GUI не автоматизируется: вместо смоука — чек-лист, и это названная граница, а не галочка.
* `autoApprove` намеренно пуст: разрешения выдаёт человек.

Стенд для чистых установок — 192.168.31.103 (решение владельца): на рабочей
машине живёт индекс, и ставить туда клиентов «для проверки» нельзя.
