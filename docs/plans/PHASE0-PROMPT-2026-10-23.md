# ПРОМПТ ЗАПУСКА ФАЗЫ 0 — «Контур и измерение»

**Назначение:** дать исполнителю (агенту) самодостаточное задание — настроить и
запустить Фазу 0 плана развития RAGRAF так, чтобы перед каждой правкой и после
неё была собрана **максимально полная и измеримая информация**, а каждое
утверждение «стало лучше/быстрее» было доказано парой замеров одним и тем же
инструментом.

**Источник требований:** `ПЛАН-РАЗВИТИЯ-RAGRAF-2026-10-23.md` (раздел 6, Фаза 0;
раздел 7, метрики; раздел 8, антипаттерны), `AGENTS.md` (разделы 2, 4, 8),
`AGENTS-TRAPS.md`.

## 0. Роль и мандат

Ты — учёный, лучший в математическом анализе. Это значит три вещи, и они обязательны:

1. **Определение раньше измерения.** Ни одна величина не измеряется, пока не
   записано её точное определение (единица, формула, способ счёта, границы
   выборки). Без этого числа в отчёте — шум.
2. **Пара «до/после» одним инструментом.** Эффект правки доказывается только
   сравнением замеров, снятых **одним и тем же кодом измерения** до и после
   правки, на **одном и том же состоянии корпуса**. Замер «после» новым
   инструментом — не доказательство.
3. **Гипотеза ≠ измерение.** Все `Δ` в плане (§5) — гипотезы. Ты заменяешь их
   измерением: `p50`, `p90`, `max`, `n` (число проб), `σ` (разброс). Если гипотеза
   не подтвердилась замером — так и пишется, это находка, а не провал.

**Мандат ограничен Фазой 0.** Шаги 0.1–0.6. Ничего из Фаз 1–3 не начинать.

## 1. Аксиоматика (заморозить до первого замера)

Запиши в отчёт дословно и не меняй по ходу:

| Термин | Определение |
|---|---|
| `p50` / `p90` / `max` | перцентили и максимум по серии **независимых** проб (см. §2) |
| `n` | число проб в серии; меньше `n=20` для перцентилей — серия несостоятельна, честно пометить |
| **неизменный корпус** | отпечаток входа (множество `(путь, размер, mtime_ns)` файлов корпуса) **побайтово равен** сохранённому `watch_fingerprint.json` последнего успешного прогона |
| **тёплый кэш** | повторный вызов той же операции на том же корпусе в том же процессе/в пределах `FRESHNESS_TTL_SEC` |
| **холодный кэш** | первый вызов после старта процесса или после `invalidate_cache` |
| **символы, сэкономленные `replaces`** | `Σ(размер файла в символах, который агенту не пришлось читать)` — счёт идёт по фактически выданным фактам со ссылкой `файл:строка`, а не по «операция заменяет чтение» |
| **единица времени** | миллисекунды, 3 знака после запятой; время стены (wall-clock) |

## 4. Шаги Фазы 0 — каждый с приёмкой-фальсификатором

Для каждого шага: **сделать → измерить ДО (baseline) → сделать → измерить ПОСЛЕ
тем же инструментом → приёмка как проверяемое неравенство → инварианты → риск.**

- **Приёмка (фальсификатор):** в реальной сессии AutoClaw ≥1 вызов `ragraf_*`;

## 5. Сквозная математическая гигиена (применять ко всем шагам)

1. **Один инструмент до/после.** Снял baseline через `tools/ragraf.py` — «после»
   снимай тем же. Смена инструмента делает сравнение недействительным.
2. **Состояние корпуса фиксируется.** Все «до/после» одной операции — на одном
   `rev_id`. Если корпус переиндексировался между замерами — серия аннулируется.
3. **Разброс, а не точечное число.** Отчёт несёт `p50/p90/max/n`; «среднее» без
   разброса для распределений с тяжёлым хвостом (здесь `catalog` = 47 c при
   `search` = 1 c) — вводит в заблуждение.
4. **Контроль смещений:** прогрев, порядок проб рандомизирован (тёплый/холодный
   вперемешку), параллельная нагрузка исключена или задокументирована.
5. **Каждый `Δ` плана помечен «гипотеза → измерение».** В финале отчёта таблица:
   что предсказывалось, что измерено, подтвердилось/нет.
6. **Пустой результат — не ошибка** (AGENTS.md §3): `found=false` с кодом 0 — факт.
7. **После правки ядра — обязательно:** `reindex`, `check`,
   `tools/Invoke-ProjectDoctrine.ps1`; в отчёте — какие запустить не удалось и почему.

## 6. Форма отчёта (обязательная структура)

1. **Baseline** — таблица B1–B7 с `p50/p90/max/n` и помехами.
2. **По каждому шагу 0.1–0.6:** что было (файл:строка) → что сделано → «до/после»
   тем же инструментом → приёмка (да/нет/опровергнута) → какие инварианты сохранены
   и как это доказано → какие проверки прошли/не прошли.
3. **Таблица гипотез:** Δ из плана против измеренного.
4. **Находки, не связанные с шагом** (посторонние дефекты — отдельно, не молча).
5. **Что осталось недоказанным** и почему (это не слабость отчёта, а честность).
