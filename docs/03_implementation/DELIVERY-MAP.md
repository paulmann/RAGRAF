## Границы, названные прямо

- Правильность текста ответа не оценивается: кейс проверяет шаги, запреты и
  наличие ожидаемых путей (`docs/03_implementation/QUALITY-CASES.md`).
- Изменение входа для каскада доказывается `sha256` версии документа, а не
  смыслом правки: правка слова помечает весь документ
  (`docs/03_implementation/STALE-CASCADE.md`).
- «Исправлено» заявляется только на той же ревизии: на другой это `other_rev`
  (`docs/03_implementation/QUALITY-TRACES.md`).
- Кейсов на живом корпусе нет: объявления — файлы проекта, а не вывод модели.
