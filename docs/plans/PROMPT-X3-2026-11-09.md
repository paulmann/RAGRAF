## 2. Задача этапа

1. **Модуль `src/ragraf/anchors.py`** — разбор размеченных блоков комментариев в
   ту же модель замысла, что и манифест:
   - `START_MODULE_CONTRACT … END_MODULE_CONTRACT`: `PURPOSE`, `SCOPE`,
     `DEPENDS`, `LINKS`, `ROLE`, `MAP_MODE`;
   - `START_CONTRACT: fn … END_CONTRACT: fn`: `INPUTS`, `OUTPUTS`,
     `SIDE_EFFECTS`;
   - `MODULE_MAP` (перечень экспортов), `START_BLOCK_*`/`END_BLOCK_*`.
   Разбор — построчный и строгий: незакрытый блок, дубль `MODULE_CONTRACT` в
   файле, ключ вне закрытого списка — находка с `path:line`, а не молчаливый
   пропуск.
2. **Единая модель.** Привязка получает поле `source`: `manifest` или `anchor`.
   Манифест главнее: якорь заполняет пробелы, конфликт — отдельная находка
   `anchor_conflict` с двумя адресами (строка манифеста и `path:line` якоря).
   Второго объявленного графа и второго хранилища не заводить.
3. **Расширение `contract_drift`, а не новая операция.** Добавить параметр
   `source` со значениями `manifest` (по умолчанию, поведение не меняется),
   `anchors`, `both`. Новые виды расхождения в закрытом списке `DRIFT_KINDS`:
   `declared_edge_missing`, `computed_edge_unexpected`, `anchor_conflict`,
   `markup_malformed`, `map_mismatch`. Список остаётся закрытым: вид вне его
   невозможен, и это проверяется.
4. **Сверка `DEPENDS` с вызовами.** `declared_edge_missing` — `DEPENDS` назван,
   фактического вызова нет: адрес якоря и, если есть, ближайший фактический
   вызов. `computed_edge_unexpected` — вызов есть, `DEPENDS` нет (только когда
   якорь в файле вообще есть, иначе шум на всём корпусе).
5. **Линт разметки.** Парность START/END, уникальность `MODULE_CONTRACT`,
   `MODULE_MAP` против фактических экспортов (`map_mismatch`), `LINKS` на
   существующий модуль манифеста (`stale_crosslink` уже есть — переиспользовать).
6. **Ничего не писать в исходники.** RAGRAF якоря не создаёт и не правит:
   sha256 всех файлов до и после прогона совпадают.

## 4. Приёмка (`tests/test_contracts_anchors.py`, группа core, песочница %TEMP%)

1. Незакрытый якорь → `markup_malformed` с номером строки.
2. Дубль `MODULE_CONTRACT` в файле → находка, а не «взяли первый».
3. `DEPENDS` без вызова → `declared_edge_missing` с адресом якоря.
4. Вызов без `DEPENDS` при наличии якоря → `computed_edge_unexpected`.
5. Конфликт манифеста и якоря → `anchor_conflict` с двумя адресами; побеждает
   манифест.
6. Проект только с якорями (манифеста нет) работает: `source=anchors`.
7. `MODULE_MAP` расходится с экспортами → `map_mismatch`.
8. Виды находок ⊆ `DRIFT_KINDS`; закрытость списка проверена.
9. sha256 исходников до и после прогона совпадают.
10. Детерминизм: два прогона на неизменном состоянии дают одинаковый отчёт.
11. Без лицензии Enterprise — прежний отказ издания.
