## Как применять

1. **Не запускай промт «в пустоту».** Приложи к сессии оба файла (промт и research) либо дай агенту путь к каталогу `C:\AutoClaw\AgentKnowledge`.
2. **Первый запрос — только ADR.** Скажи: «Прочитай PROMPT и RESEARCH. Сначала составь ADR и план P0, код не пиши». Это отсекает преждевременную реализацию и проверяет, что агент понял факты.
3. **Проверь ADR по чек-листу:**
   - используется ли существующий `session-query-sqlite` вместо нового поиска;
   - есть ли модель акторов и эпизодов;
   - учтены ли `whenToUse` и факты использования навыков;
   - read-only ли AutoClaw;
   - есть ли приватность (редакция секретов, локальность, retention);
   - есть ли расписание 2×/сутки, ручной reindex, статус;
   - есть ли `dry_run` у диспетчеризации.
4. **Дальше — P0.** Индекс + поиск + настройки + тесты. Только после зелёных критериев приёмки — P1 (AutoClaw, карточки, диспетчеризация).
5. **Каждый этап — с доказательствами:** `файл:строка`, замеры, тесты, хэши источников до/после.

## Ключевая идея в одном абзаце

В HARNESS уже есть полнотекстовый backend по истории сессий, но он выключен (`:memory:`, `openAt: never`); навыки лежат файлами с `whenToUse`, который теряется в каталоге; AutoClaw 2 хранит сессии, запуски, память и 21 именованного агента, но его FTS индексирует только `request/answer`. Поэтому максимум — включить существующий поиск, надстроить модель «актор → эпизод → навык → артефакт», подключить AutoClaw read-only и дать руководителю инструмент диспетчеризации с доказательствами.

## Что НЕ обещать

- Автономный запуск чужих агентов без подтверждения.
- Запись в AutoClaw 2 без отдельного контракта.
- Семантический поиск «из коробки»: в HARNESS нет embedding-пакетов, это опция P2.
- Полное покрытие AutoClaw FTS: его текущий индекс неполный, нужен свой.

## Следующий шаг

Если нужен не промт, а реализация: начни с P0 в отдельной ветке/профиле, включив `session-query-sqlite` с персистентным путём и добавив сервис `agent-knowledge`. Первый измеримый результат — «найти агента по вопросу» на 30 golden-запросах с recall@3 ≥ 0.80.
