# Числа поверхности: из кода, а не из текста (X2)

Документ описывает механизм, которым числа в документации перестали быть ручным
текстом. Относится к блоку 8 плана Pro/Enterprise. Обновлён: 2026-11-09.

## 1. Зачем

Числа «сколько операций, инструментов, возможностей, языков, форматов» жили в
шести README, двух десятках документов и в навыке. Каждое обновление было ручной
правкой, и расхождение обнаруживал читатель, а не сборка: в проекте измерены
54 / 59 / 61 / 66 при фактических 60 и 67.

Теперь счёт один — `src/ragraf/surface.py`, — а текст получается из него.

## 2. Устройство

| часть | что делает |
|---|---|
| `src/ragraf/surface.py` | считает поверхность: операции с параметрами и ключами ответа (разбор AST `facade.py`), инструменты MCP, подкоманды CLI, языки, форматы, возможности по изданиям; отдаёт `digest` |
| `tools/surface_counts.py` | тонкая обёртка: печатает те же числа в прежнем формате для чекера, ворот и тестов |
| `tools/surface_templates.json` | шаблоны чисел по документам и слотам; правка формулировки не требует правки кода |
| `tools/surface_gen.py` | `--check` (гейт), `--write` (числа и артефакт), `--mark` (однократная разметка) |
| `docs/surface.json` | артефакт поставки: числа, состав операций, возможности, ревизия, отпечаток |

Число в документе допустимо **только между маркерами**:

```
<!-- surface:figures -->**70 operations** on the facade, …<!-- /surface:figures -->
```

Всё вне маркеров — история. Она не проверяется и не переписывается: этим и снят
измеренный класс «история против утверждения», из-за которого правило чисел
раньше молчало.

## 3. Что покрыто

Шесть README (заголовок, абзац инструментов, абзац опубликованных чисел),
`docs/03_implementation/INTEGRATION.md` (число инструментов),
`docs/03_implementation/EDITIONS-PRO.md` (число возможностей и число Pro).

`tools/surface_gen.py --check` падает, если:

* число в маркере не совпадает с кодом (сообщение называет документ, слот,
  ожидаемое и фактическое);
* маркер объявлен в шаблоне, а в документе его нет;
* в документе есть маркер без шаблона;
* отпечаток `docs/surface.json` не совпадает с текущим.

## 4. Границы, названные прямо

- **Числа навыка** (`docs/skills/ragraf-core/**`) проверяет
  `tools/check_skill_variants.py` (правило `source_rules`); новый гейт их не
  дублирует, но читает тот же `surface.py`.
- **Alt-текст обложки** (`![…: 77 MCP tools …](assets/social-preview.png)`) не
  размечается: HTML-комментарий внутри alt попал бы в текст для чтения с экрана.
  Число там меняется руками при выпуске — это названо, а не спрятано.
- **Статья и прежние отчёты** — история, вне маркеров.
- **Сайт `ragraf.ru`** живёт вне репозитория: `--write` пишет `docs/surface.json`
  для поставки, а страницу правит отдельный промт. Гейт честно называет границу:
  удалённую страницу он не осматривает.
- **Ревизия** в артефакте обновляется, но в отпечаток не входит: иначе каждая
  переиндексация делала бы гейт красным на неизменном коде.

## 5. Ключи ответа: что видно статически

Ключи берутся из литерала `env.result = {...}`. У 47 операций ответ собирается
из переменной, и это названо в `notes` ответа `surface.collect`, а не выдано за
пустой ответ. Счёт чисел от этого не зависит; для пиннинга подписи (этап X6)
эти операции придётся описывать отдельно.

## 6. Порядок после правки кода или текста

1. `python tools/surface_gen.py --check` — увидеть расхождение;
2. `python tools/surface_gen.py --write` — записать числа и артефакт;
3. `python tools/registry_line.py --write` — пересчитать строку реестра и хэши
   переводов в таблице источников (правка README меняет их sha256);
4. `python tests/test_documented_numbers.py` — 76 проверок, включая порчу
   числа, идемпотентность, приманку и подмену отпечатка.

Шаг 3 обязателен: `check_pro_delivery.py` сверяет хэши переводов с собранной
поставкой и без пересчёта отказывает.

## 7. Как добавить документ

1. вписать шаблон в `tools/surface_templates.json` (слот + текст с `{ops}` и
   другими ключами; в шаблон включается окружение числа, иначе короткая строка
   встречается дважды);
2. `python tools/surface_gen.py --mark` — обернуть найденный текст маркерами;
3. `python tools/surface_gen.py --check` — убедиться, что сошлось.

## 8. Откат

Убрать маркеры из документов, вернуть числа руками, удалить `docs/surface.json`
и три инструмента (`surface.py`, `surface_gen.py`, `surface_templates.json`);
`surface_counts.py` вернуть к самостоятельному счёту. Данные и операции не
затронуты: этап меняет только способ получить число.
